## 📱 О проекте
Android-приложение для поиска АЗС, сравнения цен и AI-аналитики расхода топлива.
Пользователь видит карту с АЗС, получает AI-подбор лучшей станции, строит маршрут,
ведёт гараж (авто, заправки, ТО) и получает AI-рекомендации по расходу.

## 🛠 Стек
- Kotlin, Jetpack Compose, Material 3 (тёмная тема поддерживается)
- MVVM + StateFlow, Hilt (DI), Room, WorkManager
- Карты: OSMDroid; геолокация: FusedLocationProvider
- AI-роутер с fallback: DeepSeek → HuggingFace (Qwen) → GigaChat → YandexGPT
- Сеть: OkHttp (единый клиент через DI, таймауты 30 с; для роутинга 8 с)

## 🗂 Структура
- `ai/` — AI-провайдеры, AiRouter (fallback), FuelAnalysisPromptBuilder
- `data/` — GasStationRepository (assets/stations.json), Vehicle/FuelRecord репозитории, Room
- `features/dashboard/` — экран AI-телеметрии расхода
- `ui/map/` — карта, список АЗС, карточка АЗС, маршрут
- `ui/fuel/` — MapViewModel (станции, маршрут, геопозиция)
- `ui/vehicles/`, `ui/components/` — гараж и карточка авто (CarSilhouette)
- `geo/` — NominatimGeocodingProvider, OpenRouteServiceProvider (RoutingProvider)
- `worker/` — StationUpdateWorker (фоновое обновление кэша)
- `di/` — AppModule (Room, репозитории, OkHttpClient, AiRouter)

## ✅ Что работает (текущее состояние)

### Карта и АЗС
- Маркеры АЗС с цветовой кодировкой (нет топлива / очередь / ок)
- Список «АЗС рядом»: фильтры по топливу, сортировки (Лучшее/Дешевле/Ближе/Без очереди)
- Карточка «✨ AI-подбор» лучшей станции на главном экране
- Карточка АЗС: топливо с ценами, очередь, надёжность; раскрывается при выборе из списка
  (список при этом сворачивается), карточка прокручивается
- 🧭 **Маршрут**: кнопка «Построить маршрут» всегда активна — мгновенно рисуется линия
  (прямая) с плашкой «距离/время», затем в фоне уточняется по дорогам через
  OpenRouteService, если задан ORS_API_KEY; «Сбросить» очищает маршрут;
  при выборе другой АЗС старый маршрут сбрасывается автоматически
- «Открыть в навигаторе» — запасная кнопка (Google Maps)
- Кнопка 📍 (FAB) возвращает камеру к текущей позиции

### Гараж
- Карточка авто: ровный силуэт седана (градиент Teal→Amber, арки колёс, фары, дверной шов)
- Бак/запас хода, пробег, расход, число заправок, график расхода, счётчик ТО, последняя заправка

### AI-экран
- Телеметрия: средний расход (л/100 км), эффективность, ₽/км, график за 30 дней
- AI-анализ по данным заправок (мульти-провайдер с fallback)

### Системное
- Тёмная тема (isSystemInDarkTheme)
- Реальная геопозиция вместо хардкода координат
- Dashboard использует реальные АЗС (GasStationRepository), не демо-данные

## 🔑 API-ключи (local.properties — НЕ коммитится!)
- DEEPSEEK_API_KEY, HUGGINGFACE_TOKEN
- GIGACHAT_AUTHORIZATION_KEY (или CLIENT_ID + CLIENT_SECRET)
- YANDEX_API_KEY + YANDEX_FOLDER_ID
- ORS_API_KEY (маршруты по дорогам; без ключа работает прямая линия)

## 🗒 История ключевых исправлений
- Крэш на Android 7.x: java.util.Base64 → android.util.Base64
- Хардкод Челябинска → реальные координаты пользователя (StateFlow userLocation)
- Пустая кнопка 📍 → центрирование карты (recenterTick)
- Список АЗС не закрывался при выборе → сворачивается, карточка раскрывается
- Кнопка маршрута «зависала» на ожидании ORS → мгновенная прямая + фоновое уточнение
- Кривой силуэт авто → перерисован (плавные обводы, арки, фары)
