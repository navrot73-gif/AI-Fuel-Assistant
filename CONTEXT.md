# 📘 AI FUEL ASSISTANT — ПАСПОРТ ПРОЕКТА (30.08.2026)

## 🏗 Что это
Android-приложение «Где бензин?» (Россия): карта АЗС (MapLibre GL + osmdroid fallback), цены из 4+ источников,
AI-помощник (голос+чат), маршруты OSRM, гараж с заправками, метриками и фото.
- **Репозиторий:** github.com/navrot73-gif/AI-Fuel-Assistant (публичный, main)
- **Пакет:** com.navrot.aifuelassistant
- **Стек:** Kotlin, Compose, Hilt, MVVM, Room, MapLibre GL / osmdroid, Coroutines/Flow, Timber,
  Jetpack DataStore, EncryptedSharedPreferences, JaCoCo
- **Worker:** Cloudflare `ai-fuel-proxy` (navrot73.workers.dev)

## 🏁 СТАТУС ФАЗЫ 1: ЗАВЕРШЕНА ✅
Фаза 1 полностью завершена и валидирована набором интеграционных и контрактных gatelist-тестов (T1–T8):
- **Единый реестр координат (`StationRegistry`):** Гарантированный базовый офлайн-слой (100+ АЗС Челябинска), сохранение точных целевых координат при роутинге OSRM, защита от создания фантомных станций.
- **Трехэтапная эмиссия:** Emit #1 (кэш/assets, <=100мс), Emit #2 (детерминированный реестр assets, <=3с), Emit #3 (фоновое обогащение под бюджетом <=6с).
- **Плавное переключение карт:** Автоматическая цепочка фолбэков векторных тайлов (OpenFreeMap → VersaTiles → OSM raster) и бесшовное переключение на osmdroid engine при сбоях сети.
- **Диагностический трекер (`MapDiagnosticsTracker`):** Экспорт метрик тайминга, статистики реестра и статусов тайлов.

## 🚩 ОТКРЫТЫЕ ФИЧЕ-ФЛАГИ ИСТОЧНИКОВ
Все внешние провайдеры обогащения данных изолированы и по умолчанию выключены:
- `src_benzonavt` — получение оперативных цен Benzonavt (default: `false`)
- `src_russiabase` — статус наличия топлива по отчётам Russiabase (default: `false`)
- `src_overpass` — живое обогащение из OpenStreetMap Overpass API (default: `false`)

**Правило источников:** Внешние провайдеры вызываются ТОЛЬКО при включённом соответствующем флаге. Любые внешние данные могут обогащать только цены и статус наличия топлива, но НЕ могут изменять координаты или геометрию станций из реестра.

## 📜 ПРАВИЛА ПРОЦЕССА И ПРИЁМКИ PR
1. **Реестр = единственный источник координат.** Координаты АЗС берутся исключительно из `StationRegistry`.
2. **Внешние источники только под флагом + device-доказательства.** Включение или изменение логики внешних провайдеров требует записи логов/скриншотов или успешного прохождения DeviceScenarioTest на физическом устройстве или эмуляторе.
3. **PR без экспорта диагностики и ожидаемых значений НЕ принимается.** Каждый Pull Request должен содержать текстовый экспорт диагностики (`MapDiagnosticsTracker.exportDiagnosticsText()`) и таблицу с ожидаемыми контрольными метриками.

4. **Наличие диагностических доказательств:** Каждая фича или исправление сопровождается экспортом `MapDiagnosticsTracker` с валидацией таймингов (`firstEmitMs < 1000ms`, `enrichmentMs <= 6000ms`).
