# Правила для AI-ассистентов

## Ключевые архитектурные и процессные правила

### 1. Единый источник координат
- **Реестр (`StationRegistry`) — единственный источник координат АЗС.**
- Внешние источники (Benzonavt, Russiabase, Overpass и др.) могут обогащать данные цен и наличия топлива, но НЕ могут изменять координаты станций или создавать автономные точки на карте.

### 2. Внешние источники и фиче-флаги
- **Внешние источники работают только под флагом + device-доказательство.**
- Флаги внешних источников (`src_benzonavt`, `src_russiabase`, `src_overpass`) по умолчанию выключены (`false`).
- Добавление, изменение или включение внешних источников данных требует предоставления device-доказательств (скриншоты, логи выполнения или результаты DeviceScenarioTest).

### 3. Требования к PR (диагностика и контрольные значения)
- **PR без экспорта диагностики и ожидаемых значений НЕ принимается.**
- В каждом PR обязательно приводится текстовый экспорт диагностики (`MapDiagnosticsTracker.exportDiagnosticsText()` / кнопка «Экспорт диагностики») с указанием ожидаемых контрольных показателей (timing metrics, count/registry stats, active sources).

## Режимы работы

### ЗЕЛЁНЫЙ режим (мелкие задачи, делаешь сам)
Когда: меняется 1-4 файла, НЕ трогаешь build.gradle и libs.versions.toml
Делаешь: ветка -> изменения -> тесты -> PR

### ЖЁЛТЫЙ режим (большие задачи, сначала план!)
Когда: меняется 5+ файлов ИЛИ трогаешь build.gradle, libs.versions.toml,
добавляешь зависимости, меняешь навигацию или DI
Делаешь: пишешь ПЛАН в комментарий (какие файлы, какие зависимости, риски)
и ЖДЁШЬ одобрения от navrot73-gif. Без одобрения НЕ начинаешь!

## Запрещено всегда
- Отключать CI-проверки и удалять тесты
- Менять namespace, applicationId, minSdk
- Коммитить файлы .kotlin/, build/, local.properties

## Перед созданием PR обязательно
- ./gradlew assembleDebug  (BUILD SUCCESSFUL)
- ./gradlew lintDebug      (без ошибок)
- ./gradlew testDebugUnitTest (все прошли)
- Экспорт диагностики и ожидаемые значения метрик (в описании PR)
- git log --oneline -3     (показать в отчёте)
- git push origin <ветка>  (показать в отчёте)
